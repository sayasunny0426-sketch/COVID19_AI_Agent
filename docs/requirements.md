| R-16 | `AcquisitionTime` が欠けている場合の扱いと、選んだ Series に複数の画像がある場合の扱いは推測で決めない。監査で件数を確認し、該当例がある場合に研究責任者が決める | D-030 |

R-15 を実装するには、`StudyDescription` と `SeriesDescription` の実際の値のうち、どれを「胸部検査の候補」「frontal の AP / PA」とみなすかの対応表が必要になる。1,277 例のコホートを作ったときの実装にこの対応表があれば、それを使う。なければ、監査で値の一覧を作り、研究責任者の確認を受けて固定する（implementation_plan 02-2）。

これらの値は研究者が作成したもので、Claude はまだ検証していない。manifest を受け取ったら、人数、死亡数、患者の重複、hash を照合する（implementation_plan の工程 06）。

参考（上の値から計算）：死亡割合は全体で 169/1,277 = 13.2%。split の比率は 1,021 : 128 : 128 ≒ 8.0 : 1.0 : 1.0 で、T-06 の 8:1:1 を満たす。EPV の目安（1/10）は、Train を基準にすると約 13.5、全体を基準にすると約 16.9（どちらを使うかは Q-B4）。
